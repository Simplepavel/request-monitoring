# Система заявок для общежития


## Роли

- Житель
- Исполнитель
- Админ
- СуперАдмин

## Житель

### Что может делать
- Создавать заявку
- Редактировать заявку
- Смотреть список своих заявок
- Регистрация/вход
- Редактирование профиля

### Регистрация жителя
Заполнить поля:
- ФИО
- Номер общаги
- Номер блока
- Почта
- Телефон
- Пароль

### Вход жителя
Заполнить поля:
- Почта
- Пароль

### Создать заявку
Номер блока, общежития, телефон, ФИО заявителя берём с БД.
Житель выбирает, какой специалист ему нужен (сантехник, слесарь, токарь, электрик).
Дальше вводит описание проблемы (сломался туалет, не работает замок на дверной ручке).
По желанию прикладывает фото проблемы.

### Редактировать заявку
Разрешение редактировать заявку только при её отклонении исполнителем (электрик не чинит туалет), после чего пользователь получает отказ и возможность повторно отправить заявку после редактирования. Сам пользователь по своему желанию ничего с заявкой после её размещения делать не может.

### Смотреть список своих заявок
При просмотре заявок пользователь видит все свои заявки и их статусы:
- **Ожидает рассмотрения** — исполнитель ещё не увидел/не ознакомился с задачей
- **Принято в работу** — исполнитель увидел задачу и ознакомился с ней, т.е. открыл описание, увидел номер блока, ФИО заказчика и т.д., и решил, что будет её выполнять
- **Отклонено** — исполнитель увидел задачу, ознакомился с ней, но решил, что это не его профиль, и отклонил её с комментарием, что не так с заявкой
- **Ожидает подтверждения** — исполнитель увидел задачу, ознакомился с ней, связался с заказчиком и выполнил её. Теперь надо дождаться подтверждения от заказчика
- **Выполнено** — заказчик подтвердил, а исполнитель исполнил то, что от него требовалось

### Статусы заявок
Ожидает рассмотрения -> Принято в работу (или отклонено) -> Ожидает подтверждения -> Выполнено


### Редактировать профиль
- Смена ФИО
- Смена телефона/почты (с подтверждением)
- Смена общаги/блока (при переезде)

## Исполнитель

### Что может делать
- Видит список текущих заявок
- Вход
- Редактировать профиль

### Список текущих заявок
Исполнитель в главном меню видит список заявок, которые ему нужно рассмотреть:
заявки, ожидающие подтверждения + выполненные заявки + заявки, принятые в работу.

Исполнитель выбирает произвольную заявку и может:
- **принять в работу** — у заказчика меняется статус заявки на «принято в работу»
- **отклонить заявку** (+ комментарий с причиной отказа) → у заказчика появится заявка со статусом «отклонено» + причина отказа

### Вход
Всех исполнителей регистрирует админ. Вход происходит по login и по выданному паролю.

### Редактировать профиль
- Смена ФИО
- Смена телефона, почты (с подтверждением)

После принятия в работу исполнитель обязан завершить начатую заявку. Все заявки, принятые в работу, будут в соответствующем разделе («мои заявки»).

### Статусы заявок (исполнитель)
Ожидает рассмотрения -> Принято в работу -> Ожидает подтверждения -> Выполнено

> При отклонении заявка просто меняет статус у заказчика на «отклонено» и не отображается у исполнителя.

## Админ

### Что может делать
- Вход (login, пароль)
- Добавление исполнителей
- Редактирование профиля
- Удаление исполнителей
- Статистика по исполнителям (их список)

### Вход
Super admin выдаёт login и пароль, по которому будет происходить аутентификация.

### Добавить исполнителя
Ввести:
- ФИО
- Номер телефона
- Почту
- Должность
- Закреплённую общагу

Затем выдать login и пароль, по которому исполнитель зайдёт в аккаунт.

### Редактировать профиль
- Смена ФИО
- Смена почты, телефона (с подтверждением)

### Удаление исполнителя
Удаление его из базы данных.
- Все заявки, которые он выполнил, остаются в БД.
- Все заявки, которые он принял в работу и не выполнил, переходят в статус «Ожидает рассмотрения».

### Статистика исполнителя
Админ видит число выполненных задач, ФИО, login, пароль и т.д. Число задач, ожидающих завершения.

## Super-admin

### Что может делать
- Удаление админов
- Список админов
- Вход

### Вход
По login и паролю.

### Добавление админов
- ФИО
- Номер телефона, почта
- Номер общаги, за которую админ отвечает

### Удаление админа
Удаление его login и пароля из базы данных.

### Список админов
ФИО, номер общаги, login + пароль, контактные данные.



### Стек технологий

-Backend: Go (основной API), Python Flask (аналитика), C++ (вспомогательный сервис)
-БД: PostgreSQL
-Frontend: веб-клиент
-Контейнеризация и запуск: Docker
